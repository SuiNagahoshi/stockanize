# Issue #0001: アカウント/グループ管理とマルチテナント基盤

## 背景
- 現状は単一ユーザー前提で、アカウント境界および組織単位の管理機能がない。
- 将来的にクラウドDB併用へ拡張しやすいデータアクセス設計が必要。

## 要件
- アカウントの作成・管理
- アカウント単位でのデータ分離/制御
- ユーザグループ（チーム/組織相当）の作成・管理
- 将来のクラウドDB併用を見据えたアーキテクチャへの移行

## 実装方針
- Drift スキーマへ `accounts`, `user_groups`, `app_contexts` を追加
- `parts` を `account_id` / `group_id` でスコープ管理
- アクティブなアカウント/グループ文脈をDBで保持し、全クエリで適用
- データアクセス抽象 (`StockRepository`) を導入し、ローカル実装 (`LocalStockRepository`) を追加
- UI にアカウント/グループ管理画面を追加

## 完了条件
- アカウント切替で一覧・検索・編集対象が分離される
- グループ作成/切替/削除が可能
- 既存データは初期アカウントに移行される
- 既存画面の部品CRUDがスコープ付きで動作する
